# Creality K1 – Redefining Speed and Precision in 3D Printing

A responsive single-page web interface presenting the **Creality K1 3D Printer**, designed for users who value fast, intelligent, and reliable 3D printing. From high-speed performance to AI monitoring, this printer offers cutting-edge features for hobbyists, engineers, and educators.

---

## 📚 Overview

- **Project Title:** Creality K1 – Speed & Precision 3D Printing
- **Presenters:** Abdul Samad & Divyansh Pandey
- **Institution:** Khwaja Moinuddin Chishti Language University

---

## ✨ Key Features

- 600mm/s printing speed with 20000mm/s² acceleration
- CoreXY stability with precision input shaping
- AI camera, LiDAR scanning, and self-diagnostics
- 4.3” touchscreen and enclosed chamber
- Broad filament support (PLA, PETG, TPU, ABS, PA, ASA)
